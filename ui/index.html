💾 USB drives

📌 Recommended hardware layout
For long-term reliability use a small flash drive as the primary drive (it holds BOT-SYNC's install + state and stays plugged in 24/7) and connect a powered USB hub for any larger download/upload drives. The router's USB port can't safely power a spinning HDD or a high-draw SSD on its own, and pulling the primary drive while the router is on can corrupt the on-disk state. Always power the router down before removing the primary drive.

🗂️ Projects

A project nests its tagged downloads / uploads under <drive>/<slug>/. The slug is fixed at creation time. Auto-delete and auto-sync run from the daemon and apply to every entry tagged with this project (primary or mirror).

⚙️ Settings

Master switch

Turn BOT-SYNC off everywhere without uninstalling. When off, no sync jobs (uploads or downloads) will run and notifications stop firing.

Fine-grained switches — keep BOT-SYNC running but pause one direction.


Web UI session

How long a sign-in stays valid while idle. New sessions use this value; existing sessions extend on each request. Min 1 hour, max 720 hours (30 days).

Reliability & watchdog

BOT-SYNC self-recovers from crashes, killed processes and network hangs. procd respawns the daemon automatically; an external cron watchdog pings the daemon every minute and restarts it after 3 consecutive ping failures.

If a sync job runs longer than this without finishing, BOT-SYNC cancels it and fires a job.stuck notification. Set to 0 to disable the timer (not recommended).

⚡ Performance & hardware preset

Pick the profile that matches the device BOT-SYNC is running on. Each preset caps the number of simultaneous rclone children, the per-child memory ceiling, and the rclone --transfers / --checkers / buffer sizes. The default is auto-detected from total RAM on first start. The router profile is required if you are running on a 256-512 MB OpenWrt device — the desktop defaults will OOM the kernel.

Custom overrides

Only used when the preset above is set to Custom. Leave a field at 0 to inherit the router floor for that knob. Each rclone child enforces these via flags + RLIMIT_AS.

Cloud services

Choose which providers can be added under Accounts. Disabled services are hidden from the wizard and dropdowns.
